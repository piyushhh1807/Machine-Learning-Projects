# Heart Disease Prediction (Baseline Model)

This project is a beginner-level machine learning implementation to understand the use of Logistic Regression for predicting heart disease risk using a public medical dataset.

## Problem Statement
The objective is to predict whether a patient is likely to have heart disease based on medical attributes such as age, cholesterol, blood pressure, and heart rate.

## Dataset
The dataset used in this project is sourced from Kaggle and contains patient medical records with labeled outcomes.

## Approach
- Basic data cleaning
- Exploratory Data Analysis (EDA)
- Feature scaling
- Logistic Regression model training

## Results
- Model evaluated using accuracy as a baseline metric

## Limitations
- Class imbalance has not been explicitly handled
- Advanced evaluation metrics such as precision, recall, F1-score, and ROC-AUC are not included
- Regularization techniques (L1/L2) are not applied in this version

## Future Improvements
- Add confusion matrix and advanced evaluation metrics
- Apply L1 and L2 regularization
- Compare with tree-based models
- Improve feature selection

## Disclaimer
This project is for educational purposes only and is not intended for real-world medical diagnosis.
